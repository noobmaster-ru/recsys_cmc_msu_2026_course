**Козлов Кирилл Андреевич.** [Ноутбук](experiments.ipynb) · [Основная v2](../README.md).

Пять моделей переобучены с гиперпараметрами v2. Нового подбора нет; модели и результаты v2 сохранены.

## Данные и протокол

[Amazon Reviews 2023 Video Games, 0-core](https://amazon-reviews-2023.github.io/data_processing/0core.html).
Источник: 4 555 500 строк, архив 114 798 907 байт.
[URL и SHA-256](reports/source.json) · [План отбора](reports/selection_plan.json) ·
[Протокол](reports/protocol.json).

- Fit: до **2019-01-01 UTC**. Test: **2019-01-01 ≤ t < 2020-01-01 UTC**.
- Отбор: итеративный 5-core только по fit. Предусмотренные ограничения размера не потребовались.
- Все user ID — из выпуска 2023; `parent_asin` используется как item ID. Время переведено из миллисекунд в секунды.
- Запрос на начало 2019 года; история фиксирована на весь год.
- Релевантность: rating ≥ 4. Когорта: известные пользователи с ≥1 доступным релевантным товаром и ≥10 кандидатами.
- Кандидаты: весь fit-каталог минус все известные fit-товары, включая оценки 1–3. Без sampling; ties по item ID.
- При нечисловых candidate scores вся выдача заменяется популярностью положительных fit-событий. Когорта общая для всех моделей.
- Основная метрика — macro NDCG@10, дополнительная — macro Recall@10. EASE выбрана для сравнений по исходной validation v2.
- Парный bootstrap: 2 000 перевыборок пользователей, seed=42, 95%; без поправки за множественные сравнения и вариацию seeds.

| Выборка | Событий | Пользователей | Товаров |
|---|---:|---:|---:|
| Fit после отбора | **520 585** | **59 204** | **15 650** |
| Все события категории за 2019 | 441 337 | 341 461 | 34 244 |
| Test с известными fit user/item ID, все оценки | 10 092 | 5 536 | — |

Итого после отбора: **530 677 событий**. Минимальная степень пользователя и товара в fit — 5.
Все fit-события предшествуют запросу; известных fit-пар в test нет.
Матрица EASE float64 занимает 1,82 GiB без учёта остальных затрат памяти.

Итоговая когорта: **4 477 пользователей, 8 090 релевантных событий**.
Охват: **2,36%** из 343 073 положительных событий всей категории за 2019 год.
Отбор включает 2,29% событий любых оценок — это другой знаменатель.

FM использует только fit IDs/timestamps: год и месяц первого события, log-count, возраст истории и давность.
Карточки и тексты отзывов в признаки не входят.

## Запуск

Зависимости: [requirements.txt v2](../requirements.txt). Команды из корня репозитория:

```sh
python -m unittest discover -s homework_1/external_2019 -p 'test_*.py' -v
python homework_1/external_2019/render.py
python homework_1/external_2019/verify_final.py
```

`render.py` пересобирает ноутбук по отчётам без данных и весов.
`verify_final.py` проверяет локальные данные, веса и выдачи без обучения.

Полное повторение: новая копия репозитория со скриптами этого каталога, без созданных
здесь `data/` и `reports/`; последовательно `prepare.py`, `run_final.py`, `verify_final.py`, `render.py`.
Существующие результаты не перезаписываются. Режим `run_final.py --resume-saved` предназначен
для документированного прерванного запуска; завершённый test повторно не оценивается.

## Ограничения

Оценка относится к известным активным пользователям и товарам; охват положительных событий — 2,36%.
Отзыв не равен покупке или показу. История фиксирована на начало года, seed один.
Группа истории 1–4 пуста из-за fit-only 5-core.

Снимок собран позднее запроса. Доступность события предполагается по timestamp;
исторические редакции рейтингов и parent-связей не восстанавливаются.
Новые и старые test-результаты не являются парным сравнением: различаются источник, период и когорта.
Данные, веса и персональные выдачи хранятся в игнорируемой `data/`.
