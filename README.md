## Структура репозитория

```text
recsys_cmc_msu_2026_course/
├── README.md                     # Описание курса и ссылки на домашние работы
├── .gitignore                    # Общие исключения Git
└── homework_1/
    ├── README.md                 # ФИО, датасет, протокол, результаты и запуск
    ├── ressys_Домашнее задание 1.pdf
    ├── experiments.ipynb         # Выполненный EDA и сравнение пяти моделей
    ├── requirements.txt          # Зависимости ДЗ 1
    ├── .gitignore                # Локальные данные, веса, окружения и кэш
    ├── models/                   # Пять реализаций моделей с нуля
    ├── data_utils.py             # Общая индексация и подготовка fit-данных
    ├── evaluation.py             # Единый оценщик и диагностические срезы
    ├── configs/                  # Пространства подбора и финальные настройки
    ├── scripts/                  # Загрузка, обучение, оценка и воспроизведение
    ├── archive/snapshot_v1/       # Предыдущий эксперимент со snapshot-признаками
    ├── tests/                    # Проверки моделей, оценщика и запуска
    └── reports/                  # Агрегаты, протокол, аудит и графики
```

Датасеты, обученные веса и персональные выдачи в Git не загружаются.
Папка `homework_1/data/` создаётся локально при загрузке данных.
Команды ДЗ 1 выполняются из `homework_1/`: сначала перейдите в неё командой
`cd homework_1`, затем следуйте [инструкции запуска](homework_1/README.md#запуск-и-воспроизведение).
